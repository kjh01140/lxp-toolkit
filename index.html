강의 다운로더
홈/강의 다운로더/사용법

사용법

  1. LXP 강의 영상 페이지를 열고 재생합니다.
  2. 화면 오른쪽 위 패널이 자동으로 뜹니다. (안 뜨면 툴바 아이콘 클릭)
  3. “폴더 선택” 으로 저장 위치를 한 번 지정합니다.
  4. 파일명 확인 후 “이 위치에 다운로드”. 진행바가 끝나면 완료.
STEP 1

강의 영상을 재생하면 패널에 스트림이 잡힙니다

“스트림 N건 감지됨”이 뜨면 준비 완료. 안 뜨면 “이 탭 다시 검사”를 누릅니다.

STEP 2

“폴더 선택” → 저장 위치 지정 → “이 위치에 다운로드”

폴더는 한 번만 지정하면 다음부터 기억됩니다. 파일명도 확인하세요.

STEP 3

세그먼트를 순서대로 받습니다

“세그먼트 14/484”처럼 진행 상황이 표시됩니다. 탭은 열어 두세요.

STEP 4

“저장 완료”가 뜨면 끝

지정한 폴더에 .ts 파일이 생깁니다. VLC·PotPlayer·mpv로 바로 재생.

진도율은 건드리지 않습니다. 재생은 평소대로, 이 도구는 복습본만 받습니다.
kau.ac.kr 도메인에서만 동작. .ts 는 VLC·PotPlayer·mpv로 재생, convert-ts-to-mp4.bat 로 mp4 변환(ffmpeg).

바탕화면·문서 폴더 어디든. 폴더 안에 설치.bat·제거.bat·테스트.bat 가 있습니다.

STEP 3

설치.bat 더블클릭 → 파란 경고창은 “추가 정보 → 실행”

“Windows의 PC 보호” 파란 창은 서명 안 된 개인 프로그램이라 뜨는 정상 화면입니다. “추가 정보”를 누르면 “실행” 버튼이 나옵니다.

STEP 4

검은 창에 네 가지 입력

LXP 아이디·비밀번호, 학기(2026-2), 확인 주기(30m). 비밀번호는 입력해도 화면에 안 보이는 게 정상입니다.

STEP 5

“설치 완료!” + 감시 시작 알림

약 1분 뒤 테스트 알림이 한 번 뜨면 정상입니다. 창은 닫아도 됩니다. 다시 확인은 테스트.bat.

진도 현황
홈/진도 현황/사용법

사용법

  1. 브라우저에 LXP가 로그인된 상태로 LXP 아무 페이지나 엽니다.
  2. 툴바의 진도 현황 아이콘을 클릭하면 화면 오른쪽에 패널이 열립니다. 다시 누르거나 패널의 ✕로 닫으면 오른쪽 가장자리에 “진도현황” 손잡이가 남아, 거기서 다시 열 수 있습니다.
  3. 카드마다 과목 · 주차 · 마감일과 완료 / 미완료가 표시됩니다. 마감 임박순 정렬.
  4. ↻ 로 최신 상태를 다시 불러오고, “완료 포함” 체크로 이미 끝낸 영상까지 볼 수 있습니다.
  5. 다 본 영상은 카드 오른쪽 위 ✕ 로 목록에서 숨깁니다. 하단 “숨긴 항목 N개 · 모두 표시” 로 되돌립니다.
로그인 정보를 따로 저장하지 않습니다. 이미 브라우저에 로그인된 LXP 세션을 그대로 씁니다. kau.ac.kr 하고만 통신.
완료 / 미완료는 LXP 학습활동 완료 처리 기준입니다 (시청 시간 등 조건을 채웠는지). 소수점 진도율(%)은 표시하지 않습니다.
홈

확장 업데이트

확장을 쓰다 보면 패널이나 팝업에 “🔔 새 버전” 알림이 뜹니다. 크롬 웹스토어에 올리지 않은 개인 확장이라 자동 업데이트는 안 되지만, 아래 순서면 1분입니다.

새 버전 알림이 떴을 때
  1. 알림의 [받기] 클릭 → 다운로드 폴더에 zip 저장. 항상 같은 이름으로 덮어써 (1) (2) 가 안 쌓입니다.
  2. 그 zip을 더블클릭해서 엽니다 — 압축은 풀지 마세요.
  3. 안의 파일 전체 선택(Ctrl+A) → 복사(Ctrl+C).
  4. 확장이 설치된 폴더를 엽니다 — chrome://extensions 에서 개발자 모드를 켜면 각 확장 밑에 “로드된 위치” 경로가 보입니다.
  5. 그 폴더에 붙여넣기(Ctrl+V) → “대상의 파일 바꾸기” 선택.
  6. chrome://extensions 로 돌아가 그 확장의 새로고침(↻) 클릭. (또는 크롬 재시작)
버전이 올라가면 알림은 자동으로 사라집니다. 처음 설치는 각 도구의 [설치] 페이지를 보세요.
