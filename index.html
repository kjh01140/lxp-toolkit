사용법

  1. LXP 강의 영상 페이지를 열고 재생합니다.
  2. 화면 오른쪽 위 패널이 자동으로 뜹니다. (안 뜨면 툴바 아이콘 클릭)
  3. “폴더 선택” 으로 저장 위치를 한 번 지정합니다.
  4. 파일명 확인 후 “이 위치에 다운로드”. 진행바가 끝나면 완료.
진도율은 건드리지 않습니다. 재생은 평소대로, 이 도구는 복습본만 받습니다.
kau.ac.kr 도메인에서만 동작. .ts 는 VLC·PotPlayer·mpv로 재생, convert-ts-to-mp4.bat 로 mp4 변환(ffmpeg).

사용법

알림 예시와 주의사항
공지 알림
홈/공지 알림/설치

설치

설치 패키지 내려받기
LXP_alarm_setup.zip · ~13 MB
받기 ZIP
압축 해제 후, 더블클릭 → 4가지 입력
STEP 1

압축을 풀어 아무 데나

바탕화면·문서 폴더 어디든. 옮기려면 제거.bat 후 다시 설치.

STEP 2

설치.bat 더블클릭

파란 경고창은 “추가 정보 → 실행”. 서명 안 된 개인 프로그램이라 뜨는 정상 경고.

STEP 3

네 가지 입력

LXP 아이디·비밀번호, 학기(2026-2), 확인 주기(30m). 비밀번호는 화면에 안 보이는 게 정상.

STEP 4

“설치 완료!” → 창 닫기

약 1분 뒤 테스트 알림이 뜨면 정상. 이후 주기마다 자동. 다시 확인은 테스트.bat.

공지 알림
홈/공지 알림/사용법

사용법

  1. 설치 후에는 아무것도 안 해도 됩니다. 컴퓨터가 켜져 있으면 주기마다 확인.
  2. 새 강의·자료·공지가 생기면 Windows 알림이 뜹니다 (아래 예시).
  3. 지난 알림은 logs\latest_events.txt 에 남습니다.
  4. 다음 학기엔 설치.bat 다시 실행해 학기만 새로 입력.
로그인 정보는 이 PC의 config.ini 에만 저장됩니다. LXP 서버하고만 통신.
알림이 안 뜨면 Windows 알림·“집중 지원” 설정 확인. 중지·삭제는 제거.bat.
